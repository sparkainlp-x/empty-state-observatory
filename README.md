# Empty-State Observatory

A browser-based, software-only guessing game and reproducible synthetic benchmark. A visitor watches two seeded evolutions of an abstract, initially empty 32-state membrane, guesses which run received a hidden synthetic disturbance, then reveals the event and replays or exports the run.

**All traces, disturbances, scores, and benchmark results are synthetic.** This is not a model of physical universe dynamics, cosmology, quantum coherence, or hardware; no physical or hardware validation is claimed.

- **Play locally:** serve `web/` with any static HTTP server (for example, `python -m http.server 8000 --directory web`) and open `http://localhost:8000`.
- **Replay:** enter a seed and select **Replay seed**. The same seed, event, background forcing, and measurement noise reproduce the same data.
- **Export:** the game exports both aligned runs as CSV.
- **Benchmark:** `python -m empty_state_observatory benchmark --trials 200 --steps 160` reports false alarms, detection rate, delay, and misses for the consistency monitor and a scalar RMS baseline.
- **Tests:** `python -m pytest -q` and `npm test`.
- **Temporary Cloudflare preview:** after accepting Cloudflare's Terms of Service and Privacy Policy, run `npm ci` then `npx wrangler deploy --temporary`. Wrangler prints a temporary public URL and a private claim URL; the claim must be completed within 60 minutes. Never commit or log the claim link or temporary credentials.

## Model and explicit 32-state contract

The configured state space is exactly 32 vertices and exactly 32 synthetic channels. The mapping is the identity bijection: state index `i` maps to channel `i` for every `i ∈ {0,…,31}`. There is no 64-state input, implicit reduction, truncation, averaging, or runtime width inference. Invalid widths are rejected in the Python monitor tests.

The abstract membrane is a periodic ring. Its oriented edge difference is `g[i] = x[(i+1) mod 32] − x[i]`; the vertex Laplacian is the composition of the boundary and coboundary maps, `Lx = BᵀBx`. Each update uses a stable explicit heat step:

`x(t+1) = x(t) − α Lx(t) + f(t) + d(t)`, with `α = 0.18`.

For the 32-cycle, the largest Laplacian eigenvalue is at most 4, so `0 < α < 1/4` keeps the diffusion update non-expansive with non-negative eigenvalues. The initial state is the all-zero vector. This is an abstract finite-dimensional software evolution inspired by a homological-cascade / boundary-operator idea; it is not a claim about physical membranes or the universe.

Clean and disturbed runs use the same seeded background forcing and time axis. A separate pair of seeded measurement-noise streams produce the clean reference and run observation. The disturbance is a one-step, localized synthetic pulse that subsequently diffuses through the ring. All values use arbitrary simulation units and integer simulation steps.

## OES-32-inspired consistency monitor

The observer is a research-game monitor over the explicit 32-channel vector. It compares a measured run with its **time-aligned clean reference** and flags a frame when any documented residual threshold is strictly exceeded:

| Check | Definition | Default threshold |
|---|---|---:|
| Peak residual | `maxᵢ |rᵢ|` | 0.055 |
| Antipodal consistency | `maxᵢ₌₀…₁₅ |rᵢ − rᵢ₊₁₆|` | 0.045 |
| FOLD8 continuity | maximum adjacent residual difference over four cyclic 8-channel rings | 0.045 |

Here `r = observation − clean_reference`; equality is not an alarm. These are documented synthetic design parameters, not empirically calibrated operating limits. The simple baseline is a single global RMS residual threshold of `0.025` on the same aligned vectors.

The benchmark uses deterministic seed labels `bench-000000`, etc. It reports:

- **False-alarm rate:** clean frames flagged divided by all clean reference frames (plus the false-alarm count).
- **Detection rate:** disturbed trials with at least one monitor alert at or after the injected event onset divided by all disturbed trials.
- **Detection delay:** median simulation steps from event onset to the first qualifying alert, among detected trials.
- **Misses:** disturbed trials without a qualifying alert.

A pre-onset alert does not count as event detection. The checked-in `web/benchmark.json` is generated by the checked-in benchmark command and is labeled synthetic.

## Reproducibility and environment

The reference environment is pinned to Python **3.12.3** (`.python-version`) and Node.js **24.19.0** (`.nvmrc`). Runtime simulation uses only the Python and browser standard libraries; test tooling is pinned in `requirements-dev.txt`. No network request or third-party runtime dependency is needed by the game.

```sh
python -m pip install -r requirements-dev.txt -e .
python -m pytest -q
npm ci
npm test
python -m empty_state_observatory benchmark --trials 200 --steps 160 --out web/benchmark.json
python -m empty_state_observatory export --seed ESO-032 --out synthetic-run.csv
```
